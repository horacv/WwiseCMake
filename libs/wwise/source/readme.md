Copy the **"StreamManager"** folder in the **"source"** folder from your current Wwise version.\
It's installed here by default:

Windows: **C:\Program Files (x86)\Audiokinetic\Wwise_{version}\SDK\source**\
Mac: **/Applications/Audiokinetic/Wwise_{version}/SDK/source**

Include the **"Common"** and **"DefaultIOHook"** folders plus the required platform implementations:

Windows: **"Win32"**\
Mac and Linux (Unix): **"POSIX"**
